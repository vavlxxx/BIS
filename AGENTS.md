# Инструкция для ИИ агентов по работе с проектом БИС

Этот документ (`AGENTS.md`) является главным руководством (Project-Scoped Rule) для всех ИИ агентов, работающих с данным проектом. Внимательно изучите его перед внесением любых изменений в код, конфигурацию или контент сайта.

## Контекст проекта
Проект "Баланс Инженерных Систем" (БИС, biscorp.ru) — это корпоративный сайт организации, занимающейся полным циклом обслуживания систем вентиляции и кондиционирования. Сайт разработан на базе CMS WordPress с полностью кастомной темой.

### Архитектура и развертывание
- **Стек**: Docker, WordPress, MySQL 8.0, phpMyAdmin.
- **Порты**: WP — `8000`, PMA — `9999`, MySQL — `3307`.
- **Тема**: Кастомная тема расположена в директории `wp-theme` и примонтирована через Docker-том.
- **Управление**: Используйте `Makefile` (`make init`, `make up`, `make down`, `make restart`, `make logs`) для управления контейнерами.
- **Переменные окружения**: Все конфигурации (доступы к БД, ключи API, настройки SMTP) вынесены в файлы `.env` (см. `.env.template`). **СТРОГИЙ ЗАПРЕТ** хардкодить любые ключи (Dadata, SMTP, hCaptcha) прямо в код.

## Дизайн-система (Strict Guidelines)
Вы обязаны соблюдать корпоративный стиль. Любые отклонения в дизайне недопустимы.

### Цветовая палитра (`wp-theme/assets/css/base.css`)
Используйте ТОЛЬКО CSS-переменные:
- `var(--primary)`: `#70C6D4` (основной акцентный цвет)
- `var(--primary-dark)`: `#167b88`
- `var(--accent)`: `#70C6D4`
- `var(--dark)`: `#0d1118` (для фонов и контрастных элементов)
- `var(--text)`: `#111827` (основной цвет текста)
- `var(--text-light)`: `#6b7280`
- `var(--bg)`: `#ffffff` (основной фон)
- `var(--bg-alt)`: `#f5f7f8` (альтернативный фон секций)
- `var(--border)`: `#e2e8f0`

### Типографика и шрифты
- **Основной шрифт**: Google Font `Inter` (веса: 400, 500, 600, 700, 800).
- **Спецшрифт**: Класс `.bis-condensed` (для акцентных заголовков). Реализован через `font-weight: 800` и `transform: scaleX(0.68)`.
- Размеры шрифтов и высота строк реализованы через переменные (`--font-size-h1`, `--font-size-body` и т.д.) и функцию `clamp()` для адаптивности. Используйте переменные, не задавайте пиксели жестко!

### UI Элементы
- Не используй скругление углов (`border-radius`). Старайся всегда делать блоки с прямыми углами.
- Кнопки имеют классы `.btn`, `.btn-primary`, `.btn-ghost`, `.btn-outline`. Используйте их.
- Плавность интерфейса (микро-анимации) реализована через переходы (`transition: all 0.3s ease`). Всегда добавляйте интерактивные `hover`-эффекты к кликабельным элементам.

## Модульность кода
### CSS
Стили жестко разбиты на модули. Не смешивайте их:
- `base.css` — ядро, переменные, сброс стилей, глобальные классы (кнопки, лоадеры).
- `front-page.css` — стили главной страницы.
- `news.css`, `team.css`, `content.css` — стили соответствующих разделов.
- `admin-*.css` (например, `admin-projects.css`) — стилизация панели администратора WordPress.

### JavaScript
Скрипты подключаются модульно в `functions.php`:
- `site-forms.js` — обработка форм (заявки, валидация).
- `site-navigation.js` — логика меню и модалок.
- `site-home.js`, `site-team.js`, `site-project.js` — логика конкретных страниц.
- Конфигурации для JS передаются через `wp_localize_script` (объекты `bisSiteConfig` и `bisRevenueData`). Не пишите PHP-код внутри JS-файлов!

## Архитектура Backend (WordPress)
- **Custom Post Types**: Проекты (`bis_project`), Услуги (`bis_service`), Новости (`bis_news`). Для них созданы шаблоны (`archive-*.php` и `single-*.php`).
- **Интеграции**:
  - Dadata (определение города).
  - hCaptcha (защита от спама).
  - SMTP (отправка писем настроена через встроенный `PHPMailer`, переопределенный в `functions.php`).
- **SEO**: Мета-теги (OG:tags, SEO-заголовки) генерируются динамически в `functions.php`. Проекты закрыты от индексации (по фильтру `wp_robots`).

## Правила безопасности и работы для Агента
1. **Никакого хардкода**: Любые новые настройки или ключи добавляйте в `getenv()` или через функцию `bis_get_runtime_setting()`.
2. **Модульность**: При добавлении нового компонента, проверьте, в какой CSS/JS файл логичнее его добавить, либо создайте новый и подключите в `functions.php`.
3. **Версионирование**: НИКОГДА самостоятельно не используй `git` без явного на то разрешения.
